# scrshot Privacy Policy

Effective date: 2026-06-09

scrshot is a local macOS screenshot and screen recording utility. The app does not run a backend service and does not upload screenshots, recordings, audio, preferences, diagnostics, or usage data to the developer.

## Data Handling

scrshot processes the following data only on the user's Mac:

- screen content, when the user takes a screenshot or starts a screen recording
- system audio, only when the user selects a system-audio recording mode
- microphone audio, only when the user selects a microphone recording mode
- screenshots and recordings saved to a user-selected folder
- app preferences such as hotkey, theme, export behavior, save folder bookmark, and recording options
- local diagnostic logs used to troubleshoot app behavior

## Data Collection

scrshot does not collect personal data, does not track users, does not use analytics, and does not share data with third parties.

## Permissions

scrshot requests macOS permissions only for user-initiated features:

- Screen Recording permission is required for screenshots and video recording.
- Microphone permission is required only for microphone recording modes.
- Folder access is requested when the user chooses where to save screenshots and recordings.

Users can revoke Screen Recording and Microphone access in System Settings > Privacy & Security. Users can change the save folder in scrshot preferences.

## Data Retention

Screenshots and recordings remain in the user's selected local folder until the user deletes them. Local preferences and diagnostic logs remain on the user's Mac until the user removes the app data.
